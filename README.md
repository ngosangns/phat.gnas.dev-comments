# phat.gnas.dev-comments

GitHub Discussions backend for comments on [phat.gnas.dev](https://phat.gnas.dev).

Wired through the self-hosted giscusflare instance at `https://comments.sang.id.vn` (same worker as sang.id.vn), with a dedicated repository so Phat threads stay separate from the blog.

- Mapping: `pathname` (strict)
- Category: Announcements
- Site origins allowed: `https://phat.gnas.dev`, `https://kinh.gnas.dev`, `https://gn-duc-phat.pages.dev`
